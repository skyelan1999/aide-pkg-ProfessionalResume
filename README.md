# Professional Resume

Aide 的公开简历工作台。以 `.pr` 加密职业资料库管理多份个人档案、履历证据、目标公司、岗位定制简历、企业调查与投递记录。

## 功能

- 个人档案支持联系方式、职业定位、求职偏好、自定义 JSON 字段。
- 履历支持工作、项目、教育、技能、证书、语言、论文、荣誉、志愿服务及其他条目；分别记录个人贡献、成果与证据。
- 一个 `.pr` 内可以保存多份简历、不同岗位版本与正文历史；没有固定份数上限，当前单库明文容量为 **15 MiB**。
- 中文、英文及双语岗位任务；由 Aide 理解 JD、业务背景与证据，生成岗位定制内容。
- 公司实体识别、经营概况、产品/客户与业务方向、岗位背景、风险线索、面试核实问题；保留来源类别、链接、查询日期、事实/推断/未知和置信度。
- 简历每条正文关联履历 ID，未核实履历不能直接生成“已支持”陈述；生成时的资料快照独立保留。
- 简历正文编辑与历史恢复、关键词字面覆盖提示、投递/面试记录。
- 导出 Word `.docx`、Markdown、带 A4 样式的 HTML；HTML 在系统浏览器打开后可打印为 PDF。

## 安装与使用

下载 [Release](https://github.com/skyelan1999/aide-pkg-ProfessionalResume/releases) 中的 ZIP，在 Aide 插件面板导入并启用，打开 **Professional Resume**。需要支持插件工作台工具桥和文件处理器的 Aide（0.1.17.5 RC5 或后续兼容构建）；`document.read`/`document.save` 由宿主握手确认。普通工作台可通过本地文件选择器打开 `.pr`；工作区中的 `.pr` 关联由宿主文件处理器提供。

1. 新建资料库，设置至少 12 个字符的密码；也可体验完全虚构的示例。
2. 填写个人档案与履历证据，添加公司名称、岗位名称和 JD 原文。
3. 在“岗位定制”选择履历，查看完整发送内容，确认后点击“准备 Aide 任务”。
4. 复制任务指令，回到 Aide 会话发送。Aide 调用 `pr_tasks get`，使用当前联网工具调查，生成并校验结果，调用 `pr_tasks complete` 回填。
5. 回到工作台点击“取回结果”，审阅企业报告和简历，按需编辑、导出，再保存加密 `.pr`。

**准备任务不会自动启动模型请求。** 普通工作台没有通用模型调用权限，本插件复用 Aide 会话的模型与工具流程，不读取提供商 API Key、不伪造已完成的模型调用。没有联网能力时，企业报告必须标为待核实。示例、自动化测试和接口校验不证明模型写作质量或调查准确性。

## 加密与隐私

`.pr` 使用 WebCrypto 的 AES-256-GCM；PBKDF2-SHA-256 / 600,000 次派生不可导出的密钥。盐为随机 16 字节，每次保存使用随机 12 字节 IV，40 字节格式头作为附加认证数据，128 位认证标签。格式见 [FORMAT.md](docs/FORMAT.md)。技术接口参考 [MDN WebCrypto deriveKey](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveKey) 与 [Chrome 客户端加密说明](https://developer.chrome.com/docs/modern-web-guidance/guides/security/client-side-encryption)。

密码仅在当前页面本地使用，不写入插件设置、浏览器存储或任务参数。15 分钟无操作后，当前资料加密为内存草稿并锁定。关闭/刷新会丢失未保存草稿；JavaScript 环境不能保证物理内存清零。忘记密码不能恢复资料。新密码只用于之后保存的文件，旧备份仍使用旧密码。

默认发送给 Aide 的任务不含姓名、电话、邮箱、主页或自定义字段。用户填写在自由文本中的个人信息仍可能包含在内；发送前可以审阅完整任务。**选中的履历及 JD 会进入 Aide 会话和所选模型提供商**。静态文件加密不涵盖已分享内容、导出明文、聊天历史、操作系统或不可信宿主。

临时任务另用随机 AES-256-GCM 密钥加密，保存在插件安装目录外的 `.professional-resume-state/<workspace hash>/`，目录 0700、文件 0600，按 Aide 工作区身份隔离。缓存与密钥在同一信任域，不能防止已控制宿主账户者读取。任务默认 24 小时失效；访问过期任务时立即拒绝并删除，下次创建任务时清理其他过期缓存。无后台清理服务，不承诺 24 小时整物理擦除。每工作区最多 128 个临时任务；完成后可手动删除。任务删除不清除 Aide 或提供商的历史记录。

## 保存语义

- 从宿主绑定文件打开：保存先暂存**加密字节**，只有用户点击宿主“保存到原文件”并收到 `document.saved` 才显示宿主已保存；沿用宿主 SHA 版本冲突保护和来源权限。
- 新文件/本地文件选择器：通过宿主“保存文件”按钮或浏览器下载导出 `.pr`。准备或请求下载不等于落盘成功，须核对文件。安全页提供用户自行确认状态的按钮，该按钮不写磁盘。
- 新增、修改、取回结果都先进入内存。保留多份加密备份，并在迁移或更换密码后确认新文件能打开。
- Word、Markdown、HTML 是明文导出，包含个人档案中的联系方式。只在明确点击导出时创建。

## 开发与验证

无运行时 npm 依赖；开发浏览器测试使用固定版本 Playwright。

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run package
```

构建使用随仓库保存的 Aide MIT 工作台客户端，不依赖其他插件私有实现。包按显式文件白名单生成，不打包 `.pr`、任务缓存、测试输出、`.git` 或 `node_modules`。公开仅包含代码、虚构样例、许可证和文档。测试与限制见 [VERIFICATION.md](docs/VERIFICATION.md)，Aide 工具用法见 [AI-GUIDE.md](AI-GUIDE.md)。

企业调查是求职辅助，未知不是低风险。引用和结构校验不证明事实，简历须由本人核实后使用。本插件不会自动投递、发送邮件或联系公司。
