# Professional Resume

This repository is a public MIT Aide plugin. Never commit real resumes, contact information, passwords, credentials, task caches, `.pr` data, or private plugin source. Use fictional data for tests. Keep implementation and packages in this repository; Aide core integration uses the existing workbench/file bridge and tools.

Build with `npm run build`, test with `npm test`, package with `npm run package`. The release ZIP uses an explicit allowlist. Verify UI in a real browser and distinguish fixture/model/source checks from real paid inference, factual company research and host save/download confirmations. Do not call a model, send applications or contact companies without user intent. Unknown facts must stay unknown.

Public bugs and acceptance reports belong in `skyelan1999/aide` Issues with module `Professional Resume`, implementation repository and exact version. Task artifacts and evidence stay in this owning repository.
