# 0.1.1 · 工作区与引用文件

新增“文件与来源”页面，以及顶部“打开工作区 / 引用”“另存到来源”。可以浏览当前工作区和宿主已启用的本地、Skill、SFTP、工作区SFTP引用。来源名称和读写标记由宿主返回，不向页面暴露密码、私钥、宿主令牌或连接设置。

从这些来源打开 `.pr` 后，文件在当前页面解密。修改后可保存到原位置；只读引用可打开、编辑内存草稿，但保存时需要另选可写来源。新文件也通过另存为创建。选择目标及加密分块暂存都不写目标文件，只有真实点击宿主顶部保存按钮才提交。收到回执并核对版本后，插件才显示已保存。

另存为遇到已有文件先明确确认，再固定其 SHA-256；确认期间或提交前发生修改时拒绝覆盖。新目标在选择和提交时都必须保持不存在，使用宿主既有排他发布逻辑，不能覆盖后来出现的文件。目录必须已经存在，不跟随符号链接，不允许绝对路径或越过来源根。

Word、Markdown和打印版HTML的导出对话框可选择本机下载或工作区/引用。它们是明确的明文导出。保存后恢复 `.pr` 的原文件绑定及原版本；原库在此期间变化时，不能自动刷新基线并覆盖。

宿主暂存未完成或待确认时，先保存或明确“放弃暂存”，再选择其他文件。错误密码、取消打开或读取时文件变化会保留原资料与原绑定。放弃暂存只清理尚未提交的草稿，不撤销已经完成的保存。结果不明确时请先核对目标文件。

这项能力需要配套 Aide 的 `files.select` 握手和 `workbench.fileAccess` 声明。旧宿主仍支持原有本机文件与下载，以及从宿主文件面板打开的 `.pr` 保存；不会把缺失的新能力显示为已支持。Aide 正式发行镜像是否包含本扩展应以其版本与握手为准，插件安装本身不升级宿主。

`.pr` 的15MiB明文容量、PRDB v1二进制格式和AES-GCM加密保持不变。模型会话不获得此手动文件通道；对AI隐藏的引用可以由用户手动选择，但不因此对模型开放。源自引用的履历如果要交给Aide，仍须在岗位定制中明确选择并确认分享。

验收与未验证范围记录在 [VERIFICATION.md](VERIFICATION.md)。
